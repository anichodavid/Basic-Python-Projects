# Python Projects

A collection of Python projects I built while learning Python. Each project is self-contained and demonstrates different programming concepts.

## Projects

### 1. Contact Book
A CLI contact manager that stores names, phone numbers, and emails in a JSON file.
- Add, view, search, edit, and delete contacts
- Duplicate name/phone/email detection
- Case-insensitive search
- Persistent storage with `contacts.json`

**Skills:** Dictionaries, JSON, file handling, input validation, loops

---

### 2. To-Do List
A text-based task manager with persistent storage.
- Add, view, delete, and clear all tasks
- Tasks saved to `tasks.txt`
- Confirmation before clearing all tasks

**Skills:** Lists, file handling, loops, conditionals

---

### 3. Quiz App
A 5-question multiple-choice quiz with scoring.
- Questions stored in a dictionary
- Tracks correct and wrong answers
- Shows final score and a report card

**Skills:** Dictionaries, loops, scoring logic, input validation

---

### 4. Number Guessing Game
A guessing game with a 3-attempt limit.
- Random number between 1 and 100
- Hints: "Too high" / "Too low"
- Tracks attempts

**Skills:** `random` module, `while` loops, conditionals

---

### 5. Simple Calculator (CLI)
A menu-driven calculator.
- Add, subtract, multiply, divide
- Handles division by zero
- Input validation

**Skills:** Functions, conditionals, `try/except`

---

### 6. Prime Number Checker
Checks if a number is prime and sums all primes up to N.
- Optimized with `√n` cutoff
- No `sum()`, no `range()` — pure `while` loops

**Skills:** Loops, functions, math logic

---

### 7. Recursive Functions
Four recursive implementations:
- `digit_sum(n)` — sum of digits
- `reverse_text(text)` — reverse a string
- `count_char(text, ch)` — count character occurrences
- `power(base, exp)` — exponentiation without `**`

**Skills:** Recursion, base cases, call stack

---

### 8. Balanced Brackets
Checks if brackets in a string are balanced using a stack.
- Supports `()`, `[]`, `{}`
- Detects mismatched and unclosed brackets

**Skills:** Stacks, dictionaries, loops

---

### 9. Spiral Order Matrix
Returns all elements of a matrix in spiral order.
- Handles empty, single-row, and single-column matrices

**Skills:** 2D lists, boundary tracking, loops

---

### 10. Insertion Sort
Sorts a list in place and counts comparisons and shifts.
- Demonstrates O(n²) sorting
- Shows performance difference between sorted and reversed input

**Skills:** Sorting algorithms, in-place operations, counting

---
